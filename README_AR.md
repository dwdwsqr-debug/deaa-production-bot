# بوت إدارة الأعمال والإنتاج — نسخة تجريبية

- يستقبل صور كروت الإنتاج.
- المطابقة تعتمد على **الصنف + المرحلة/المكنة**.
- تكرار الصنف أو المرحلة منفرداً مسموح، لكن لا نكرر نفس الزوج.
- النسبة الأساسية: الكمية المنجزة ÷ المعدل اليومي × 100.
- عند تعدد الكروت، يحسب كل كرت منفرداً ثم يجمّع الإحصاء حسب النظام المتفق عليه.

لا تضع Token الحقيقي داخل الكود ولا ترسله في المحادثة.
ضعه كمتغير بيئة باسم `TELEGRAM_BOT_TOKEN`.

تشغيل:
1. `pip install -r requirements.txt`
2. عيّن `TELEGRAM_BOT_TOKEN`
3. `python bot.py`

هذه النسخة تثبت اتصال تيليغرام أولاً؛ ثم نضيف قراءة الصورة وتعبئة جدول المعدلات.
